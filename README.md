# ServiceHub – Service Management System

## 📌 Project Overview

ServiceHub is a web-based Service Management System designed to simplify service request handling and improve coordination between users, administrators, and technicians. It provides a centralized platform to create, manage, assign, and track service requests efficiently.

## ✨ Features

- **User Authentication:** Secure login and role-based access.
- **Service Request Management:** Create and manage service requests with categories, descriptions, and priority levels.
- **Status Tracking:** Monitor the progress of service requests.
- **Technician Assignment:** Assign service requests to technicians.
- **Staff Management:** Manage staff details and responsibilities.
- **Customer Feedback:** Collect feedback and service ratings.
- **Admin Dashboard:** Monitor service activities and manage operations.
- **CRUD Operations:** Create, read, update, and delete relevant records.

## 🛠️ Technology Stack

- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Frontend:** HTML, CSS, JavaScript
- **API Development:** REST APIs

## ⚙️ Application Workflow

1. Users log in and submit service requests.
2. The system stores service request details in the database.
3. Administrators review requests and assign technicians.
4. Technicians update the request status as work progresses.
5. Users track their requests and provide feedback.
6. Administrators monitor service activities through the dashboard.
